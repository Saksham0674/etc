# etc

My Personal dotfiles.

## Stack
- WM: AeroSpace
- Term: Ghostty
- Mux: tmux
- Shell: zsh
- Editor: nvim / code

## Installation
```sh
git clone https://github.com/yourusername/etc.git ~/repos/etc
cd ~/repos/etc
./install.sh
```

## Structure
- `aerospace/` - Window manager rules and routing
- `ghostty/` - Terminal configuration
- `tmux/` - Multiplexer and custom pane navigation
- `nvim/` - Editor configuration (Everforest, Lazy)
- `vscode/` - Settings mapped to nvim/tmux muscle memory
- `zsh/` - Shell configuration (XDG compliant, cached init)
- `docs/` - macOS bootstrap instructions and gotchas
